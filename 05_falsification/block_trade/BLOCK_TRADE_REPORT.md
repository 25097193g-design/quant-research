# 大宗交易因子 · 调查报告

> Week1 后半资金面调查的子项。结论:**因子不成立(PIT-correct 多空夏普0.34)**,但调查过程是个完整的方法论案例。
> 2026-08-04 整理。脚本/产出全在 `projects/week1_capital_flow/`。

---

## 一、数据收集

**为什么找大宗交易**:本来要做主力净流入(akshare `stock_individual_fund_flow`),但东财把我 IP 封了(批量冲撞后遗症,0.1s秒拒)。转而发现 **rqdatac 的 `get_block_trade` 教育版可用**(不受IP封,且融资融券/北向都被教育版封了),就改用它。

| 项 | 内容 |
|---|---|
| 源 | `rqdatac.get_block_trade(order_book_ids, start_date, end_date, market='cn')` |
| 字段 | `price`(成交价)、`volume`、`total_turnover`(成交额)、`buyer`/`seller`(买卖方营业部名)、`trade_date` |
| 抓取方式 | 分块(chunk 500股)拉全 PIT 主板 universe(~3396股),拼成全量 |
| 时期 | **2023-08-01 ~ 2026-07-30**(约3年) |
| 规模 | **47116条**大宗交易,**2484只**股(有大宗的),每月截面中位 **~318只**(大中盘为主) |
| 折溢价 | prem = 大宗成交价 / 当日收盘 - 1(用 `mainboard_price` 的 trade_date 收盘对齐) |

**数据特点**:大宗交易是**机构间大额撮合**(>交易所门槛),带买卖方营业部名称——理论上比"按单子大小猜主力"的主力净流入干净。

---

## 二、信号构造

| 信号 | 定义 | 含义 |
|---|---|---|
| **prem** | 大宗价/收盘-1 | 正=溢价(机构愿高价抢筹),负=折价(出货)。全样本中位 **-1.8%**(多数折价) |
| bcnt | 每月大宗笔数 | 机构活跃度(易被拆单干扰) |
| btot | 每月大宗成交额 | 机构资金量 |
| prem_dev | prem − 该股过去12月prem均值(shift1) | "异常折溢价"(自身纵向偏离) |

## 三、实验演进(v1 → v2 → v3 → 验证)

### v1 `block_trade_ic.py` — 原始截面 IC
- 月度截面 Spearman rank IC,前向 1m/3m。
- 结果:**prem 1m IC0.040 / 3m IC0.053,ICIR 0.31-0.35**(刚过0.03门槛,ICIR略低于0.4)。bcnt无信号,btot弱正。

### v2 `block_trade_factor_v2.py` — 中性化 + 复合因子 + 多空回测
- 中性化:行业去均值 → 市值十档去均值(顺序 demean)。
- 复合因子 = prem_n + 0.5×btot_n。
- 多空回测:top20% 多 / bot20% 空,月调。
- 结果:prem ICIR0.42、btot0.52、**复合ICIR0.53、复合多空夏普1.21**。看着像真alpha。

### v3 `block_trade_factor_v3.py` — PIT + 5条修复(按用户review)
1. **PIT**:signal_date=下个交易日(T+1公告),按 signal 月末聚合,前向收益从signal月。
2. 换手 guard(`len(long)==q`)。
3. cap 分组改 `rank(method='first')`(避免 qcut 丢组)。
4. 复合权重扫 0.3/0.5/0.7。
5. 加 prem_dev(12月自身偏离)。
- 结果:prem ICIR0.37、**复合ICIR0.45、复合多空夏普0.34**(从1.21崩)。

### 验证 `block_trade_pit_verify.py` — 隔离日期效应
- 同套代码,只换 trade_ym↔sig_ym:trade_date **夏普0.92**,PIT **0.34**。
- 确认 0.92→0.34 纯 PIT 效应(非bug);且 v2 的1.21还叠了 cap 丢组artifact(rank-first 后 trade_date 是0.92)。

## 四、判决

| 指标 | v2(前视) | v3(PIT) |
|---|---|---|
| 复合 ICIR | 0.53 | 0.45 |
| 复合多空夏普 | 1.21 | **0.34** ❌ |
| 多头夏普 | 0.54 | 0.51(稳健) |

- **多空夏普0.34 < 0.7 → 因子不成立**。
- 信号对时点 fragile(1天shift摆0.92↔0.34,3.5倍)。
- **前视主要喂的是空头腿**;多头腿PIT下~0.51稳健(~10%/yr),但高换手、非LS。
- 资金面全 kill(含大宗),rigorously confirmed,印证"净流入带批判"。

## 六、怎么做更好(改进方向,按潜力排序)

### 🥇 最有潜力:利用买卖方营业部名(完全没用)
- 数据里的 `buyer`/`seller` 营业部名是**金矿**——能构造"机构席位净流入":识别重复出现的席位、知名游资/机构席位,追踪其净买卖。比 prem 更直接反映"谁在拿货/出货"。
- 我们完全没碰这个维度。

### 🥈 数据/样本
1. **拉长回测**:rqdatac 能拉到2010s,做7-8年跨regime,确认0.34不是这2.9年偶然。
2. **精确PIT**:rqdatac 只有 trade_date、没公告时间戳。中国大宗是**T日盘后披露**→严格说T日收盘就可知,v2(trade_date)可能才是对的、v3(T+1)略保守。**真值在0.34~0.92之间**;要钉死得找带披露时间戳的源。
3. **prem_dev 流动性bias**:低流动股大量缺值,引入偏差。加最低大宗笔数门槛,或对 prem_dev 再做流动性中性化。

### 🥉 因子构造
4. **中性化用回归残差**:现在"顺序去均值",改每月截面 OLS `prem ~ industry哑变量 + log(cap)` 取残差,更严谨。
5. **多头-only低换手版**:多头~0.51夏普PIT稳健,但月调换手78%。做3月平滑/季度调仓,降换手看净夏普能不能保住。
6. **prem 细化**:按金额加权(大额权重大)、剔除异常折价、prem 行业内 z-score。

### 验证
7. **扣成本压力测试**:0.34夏普+78%换手,按0.3-0.5%往返算净收益;多头腿扣成本后剩多少。
8. **分regime/分市值组**:红利vs成长、大vs中盘,信号稳定性。
9. **多空累计曲线**:看是不是某几个月撑起来的(集中度)。

## 七、方法论收获(写进框架因子准入标准)
1. **资金/舆情/另类信号,PIT是第一杀手**——先问"信号哪天才能真正知道"再看夏普。
2. **中性化细节有影响**:qcut 丢组(duplicates='drop')会微调结果,用 rank(method='first') 更稳。
3. **IC 稳 ≠ LS 稳**:IC测全分布、LS测极端值,前视可能只喂极端值→IC小掉、LS大崩。两者都要看。
4. 一个看着1.21的alpha,被"中性化细节+PIT"两道关审回0.34。
