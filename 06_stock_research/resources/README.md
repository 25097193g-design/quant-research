## 三因子需求框架（研究紫金的宏观坐标）

- **金** = 货币信用对冲：WGC口径2025年总需求首破5,000吨、央行购金863吨（2022-24连续3年>1,000吨）
- **铜** = 电气化beta：全球精炼铜需求~2,700-2,800万吨，ICSG 2025年缺口~15万吨；EV单车83kg vs 燃油23kg
- **锂** = 周期反转期权：2025年过剩4.5-5万吨LCE → 2026年转向短缺~2.2万吨（Benchmark/Skillings口径）

## 学习路线建议（三遍读法）

1. **第一遍（框架）**：摘要7页 → 年报p10-33（摘要+资源储量+产品分册），建立"有什么矿、多少量、在哪"的地图
2. **第二遍（经营）**：p34-61 MD&A+展望，对照 2024年报 同章节看变化；重点搜"卡莫阿""巨龙""马诺诺""拉果措"四个增量项目的爬坡表述
3. **第三遍（财务）**：p113-121 三表 + 分部报告（收入按矿种拆分），算单位售价/单位成本C1，对照 Freeport/Barrick 季报交叉验证
